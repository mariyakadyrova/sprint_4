# BooksCollector — тесты на pytest

Проект с юнит-тестами для класса `BooksCollector`. Тесты покрывают операции добавления книг, назначения жанров,
отбора «детских» книг, работы со списком избранного и выборок по жанрам

## Как запустить тесты

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install pytest
pytest -vv

main.py                 # реализация BooksCollector
test_books_collector.py # тесты pytest

Что покрыто тестами
1) add_new_book
✅ Добавление книги с валидным именем.
✅ Запрет дубликатов (повторное добавление не меняет состояние).
✅ Граничные значения длины имени (параметризация):
len(name) == 40 → добавляется;
len(name) == 0 и len(name) == 41 → не добавляется.
2) set_book_genre
✅ Жанр устанавливается только если книга существует и жанр входит в допустимые.
✅ Недопустимый жанр игнорируется — жанр книги не меняется.
✅ Попытка установить жанр несуществующей книге не изменяет состояние.
3) get_book_genre
✅ Возвращает корректный жанр для существующей книги.
✅ Возвращает None для отсутствующей книги.
4) get_books_with_specific_genre
✅ Возвращает только книги указанного жанра.
✅ Возвращает пустой список, если книг с таким жанром нет.
5) get_books_genre
✅ Возвращает актуальный словарь после нескольких добавлений и назначений жанров.
6) get_books_for_children
✅ Исключает книги с возрастным рейтингом (Ужасы, Детективы из genre_age_rating).
✅ Включает книги «детских» жанров (например, Мультфильмы, Комедии).
7) add_book_in_favorites
✅ Добавляет в избранное только книги, которые есть в books_genre.
✅ Не допускает дубликатов в избранном.
8) delete_book_from_favorites
✅ Удаляет книгу из избранного, если она там есть.
✅ Без ошибок игнорирует удаление книги, которой нет в избранном.
9) get_list_of_favorites_books
✅ Возвращает фактический список избранных после операций добавления/удаления.
